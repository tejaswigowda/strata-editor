Cut a scene into named parts #

SEG on a furnished room: one mesh, 538 texture islands, no part that is one island. SEG joins the islands that touch into components, measures them in the world frame, places everything you did not name on the nearest anchor you did, and checks the cut; you supply the anchors and their names. Says where the checks fired on the first attempt. Built with the JS Shell.

Name every part of a street-corner diorama #

SEG on a 71-mesh street-corner diorama whose biggest mesh has 3,297 texture islands: too many to anchor individually. An agent names 22 regions from orthographic views, cuts nine meshes into 124 named, classed parts, names the 62 meshes that were already separate, and selects one object across all its materials with a class. Says where SEG's own warning caught a second post box, and that the cut replays. Built with the JS Shell.
