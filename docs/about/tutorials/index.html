Cut any textured mesh into named parts

The editor's SEG tool on any one-piece textured model: read the UV islands and painted colours, decide what each piece is, and cut it into named, classed meshes in one undo step. An avocado is the easy case, a toy duck the hard one (ten islands, six parts), an animated fox shows a skinned mesh cut with its skeleton and clips intact, and the page says where the method stops working. Built with the JS Shell.

Cut a scene into named parts

SEG on a furnished room: one mesh, 538 texture islands, no part that is one island. SEG joins the islands that touch into components, measures them in the world frame, places everything you did not name on the nearest anchor you did, and checks the cut; you supply the anchors and their names. Says where the checks fired on the first attempt. Built with the JS Shell.

Cut an avocado into named parts, building the tool by hand

The editor's SEG tool, written out by hand on a one-piece avocado: read the evidence the file carries (separate patches of the texture, and the colours painted on them), cut it into five named, classed meshes (skin, pit, cavity, flesh, edge) without losing a triangle, and check the cut. Says plainly where the method stops working. Built with the JS Shell.
