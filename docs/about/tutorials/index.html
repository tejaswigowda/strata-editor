Tutorials

Step-by-step walkthroughs for building animated 3D shorts with Strata — by hand, no AI required.

  • Make a Pythagorean-theorem short →
    Build three squares and a right triangle, animate the classic dissection proof, add a background, and end on a living call-card — all with the JS Shell and the Universal Timeline.
  • Build a night scene from scratch →
    Reusable helper functions, a noise-displaced ground, a grouped structure, night lighting (and the Environment setting that silently undoes it), a moving object, and a static hero camera — the full from-scratch workflow.
  • Add a static hero camera to a render sequence →
    A focused deep-dive on just the Render tab's Camera Sequence feature — add a fixed, non-animated camera and cut it in to showcase one moment your main animated camera doesn't frame well.
  • Build a table-view pong scene →
    Build Pong as a real receding table instead of a flat arcade screen — pick the depth axis before placing anything, group parts with one AddObjectCommand, verify camera framing by projecting points to NDC, and swap the backdrop for a sunset desert without touching the table.
  • Build a bubble shooter scene →
    Build the scene, not the game: a lane, exactly one class-tagged Bubble template for runtime logic to clone and recolor, a rainforest background, and a wooden single-score sign — plus two real bugs (a local-space distance offset, and JavaScript's negative modulo) worth checking for.
