# Build a wizard hat and sculpt a face into it

[All tutorials](https://strataeditor.dev/about/tutorials/)

<p class="tagline">Two ideas in one scene. First, a floppy purple hat assembled from primitives — a lathe-turned brim, a three-section cone that bends, a band, a buckle and extruded stars. Then the part that is not a texture: a smiley face <strong>sculpted</strong> into the cone by pushing a dense mesh&#39;s surface outward along its normals, as one undoable step. Open the <a href="https://strataeditor.dev/">editor</a>, open the <strong>Shell</strong> tab, and paste each block in order — or open the finished hat, <a href="https://strataeditor.dev/#repo=tejaswigowda/test1&amp;file=hat.json&amp;branch=main">hat.json</a> (<a href="#open-finished">step 7</a>).</p>

<figure>&#10;		<img src="https://strataeditor.dev/about/tutorials/screenshots/wizard-hat.png" alt="A purple wizard hat with a wide curled brim, a cone that bends at the tip, a dark band with a gold buckle, gold stars, and a raised smiley face sculpted into the front of the cone.">&#10;		<figcaption>The finished hat: lathe brim, bending cone, band and buckle, stars — and a relief smiley sculpted into the front.</figcaption>&#10;	</figure>

<div class="note"><strong>Pasting long blocks into the Shell:</strong> if <kbd>Enter</kbd> seems to do nothing after a long paste, press <kbd>Esc</kbd> first (it closes the autocomplete dropdown that was swallowing the keypress), then <kbd>Enter</kbd>. On a non-empty scene, run <code>clearScene()</code> first.</div>

<h2><span class="step">1</span> Materials and the brim</h2>

<p class="lede">Three materials: the purple everywhere, a darker purple for the band and gold for the buckle and stars. A fourth, <code>jointMat</code>, is the same purple with a <em>polygon offset</em> — step 2 explains why. The brim is a <code>LatheGeometry</code>: one 2D profile (radius, height) spun around the y axis. The profile runs out along the underside, up the curled rim, and back along the top, so the brim has thickness and an upturned edge from a single list of points:</p>

<pre><code>const purple = new MeshStandardMaterial({ color: 0x6a2bb8, roughness: 0.65, side: THREE.DoubleSide });&#10;const bandMat = new MeshStandardMaterial({ color: 0x2e1260, roughness: 0.5 });&#10;const gold = new MeshStandardMaterial({ color: 0xffd54a, roughness: 0.3, metalness: 0.7, emissive: 0x3a2a00 });&#10;// Same purple, pushed back in depth so it never z-fights the cone walls it overlaps&#10;const jointMat = new MeshStandardMaterial({ color: 0x6a2bb8, roughness: 0.65, side: THREE.DoubleSide, polygonOffset: true, polygonOffsetFactor: 8, polygonOffsetUnits: 8 });&#10;&#10;const hat = new Group();&#10;hat.name = &#39;Wizard Hat&#39;;&#10;&#10;// Brim: a lathe profile that dips, then curls up at the rim (out along the underside, back along the top)&#10;const brimProfile = [[0.85,0.02],[1.2,0.0],[1.7,-0.02],[2.05,0.04],[2.2,0.14],[2.2,0.18],[2.15,0.19],[2.0,0.1],[1.7,0.05],[1.2,0.06],[0.85,0.08]].map(p =&gt; new THREE.Vector2(p[0], p[1]));&#10;const brim = new Mesh(new LatheGeometry(brimProfile, 64), purple);&#10;brim.name = &#39;Brim&#39;;&#10;hat.add(brim);</code></pre>

<h2><span class="step">2</span> The cone: three sections that bend</h2>

<p class="lede">A single cone cannot flop over, so build it in three tapering sections. Each section is a <code>Group</code> parented to the top of the previous one and rotated a little more (<code>-0.25</code>, then <code>-0.5</code> radians); the cylinder inside is offset up by half its height so the group&#39;s origin is the hinge. Because every section inherits its parent&#39;s rotation, the bend accumulates into a curl. A sphere sits at each hinge, with the same radius as the section below, to fill the wedge that opens on the outside of the bend:</p>

<pre><code>const H1 = 1.3, H2 = 1.2, H3 = 1.1;&#10;const seg1 = new Group(); seg1.name = &#39;Crown Section 1&#39;; seg1.position.y = 0.07; hat.add(seg1);&#10;const m1 = new Mesh(new CylinderGeometry(0.72, 0.95, H1, 64), purple); m1.name = &#39;Crown 1&#39;; m1.position.y = H1 / 2; seg1.add(m1);&#10;&#10;const seg2 = new Group(); seg2.name = &#39;Crown Section 2&#39;; seg2.position.y = H1; seg2.rotation.z = -0.25; seg1.add(seg2);&#10;const j1 = new Mesh(new SphereGeometry(0.72, 64, 32), jointMat); j1.name = &#39;Joint 1&#39;; seg2.add(j1);&#10;const m2 = new Mesh(new CylinderGeometry(0.42, 0.72, H2, 64), purple); m2.name = &#39;Crown 2&#39;; m2.position.y = H2 / 2; seg2.add(m2);&#10;&#10;const seg3 = new Group(); seg3.name = &#39;Crown Section 3&#39;; seg3.position.y = H2; seg3.rotation.z = -0.5; seg2.add(seg3);&#10;const j2 = new Mesh(new SphereGeometry(0.42, 64, 32), jointMat); j2.name = &#39;Joint 2&#39;; seg3.add(j2);&#10;const m3 = new Mesh(new CylinderGeometry(0.05, 0.42, H3, 64), purple); m3.name = &#39;Crown 3&#39;; m3.position.y = H3 / 2; seg3.add(m3);&#10;const tip = new Mesh(new SphereGeometry(0.07, 16, 12), purple); tip.name = &#39;Tip&#39;; tip.position.y = H3; seg3.add(tip);</code></pre>

<div class="note"><strong>A bug worth checking for.</strong> The hinge spheres are almost, but not exactly, inside the cone walls, so with the default material they <em>z-fight</em> with them and a sawtooth edge appears at every bend (it gets worse the more finely the cone is tessellated). Shrinking the spheres does not cure it. Giving the joints their own material with <code>polygonOffset</code> pushes them slightly back in depth, so the cone walls always win the tie and the sphere only shows where the bend genuinely opens a gap. Matching the segment counts (64 on the cones and spheres) shrinks what is left.</div>

<h2><span class="step">3</span> Band, buckle and stars</h2>

<p class="lede">The band is a cylinder whose two radii are read off the cone&#39;s own radius function <code>r1(t)</code> (radius at height <code>t</code>), so it hugs the slope instead of floating or sinking. The buckle is a box with a smaller dark box as its hole. The stars are a 10-point <code>Shape</code> (alternating outer and inner radius) run through <code>ExtrudeGeometry</code>; each is placed on the cone at an angle and then tipped by the cone&#39;s slope so it lies flat against it:</p>

<pre><code>const r1 = t =&gt; 0.95 - 0.23 * (t / H1); // crown 1 radius at height t&#10;const band = new Mesh(new CylinderGeometry(r1(0.36) + 0.02, r1(0.14) + 0.02, 0.22, 40), bandMat);&#10;band.name = &#39;Hat Band&#39;; band.position.y = 0.25;&#10;seg1.add(band);&#10;const buckle = new Mesh(new BoxGeometry(0.3, 0.28, 0.06), gold);&#10;buckle.name = &#39;Buckle&#39;; buckle.position.set(0, 0.25, r1(0.25) + 0.05); buckle.rotation.x = -0.1;&#10;seg1.add(buckle);&#10;const hole = new Mesh(new BoxGeometry(0.16, 0.14, 0.07), bandMat);&#10;hole.name = &#39;Buckle Hole&#39;; hole.position.set(0, 0.25, r1(0.25) + 0.055); hole.rotation.x = -0.1;&#10;seg1.add(hole);&#10;&#10;// Gold stars, tilted to hug the cone&#39;s slope&#10;const starShape = new Shape();&#10;for (let i = 0; i &lt; 10; i++) {&#10;  const a = Math.PI / 2 + i * Math.PI / 5, r = i % 2 ? 0.07 : 0.17;&#10;  i ? starShape.lineTo(Math.cos(a) * r, Math.sin(a) * r) : starShape.moveTo(Math.cos(a) * r, Math.sin(a) * r);&#10;}&#10;starShape.closePath();&#10;const starGeo = new ExtrudeGeometry(starShape, { depth: 0.02, bevelEnabled: false });&#10;const slope = Math.atan(0.23 / H1);&#10;[-0.9, 0.9, 2.4, 3.9].forEach((ang, i) =&gt; {&#10;  const star = new Mesh(starGeo, gold);&#10;  star.name = &#39;Star &#39; + (i + 1);&#10;  const t = 0.85, r = r1(t) + 0.005;&#10;  star.position.set(Math.sin(ang) * r, t, Math.cos(ang) * r);&#10;  star.rotation.order = &#39;YXZ&#39;;&#10;  star.rotation.y = ang;&#10;  star.rotation.x = -slope;&#10;  seg1.add(star);&#10;});&#10;&#10;editor.execute(new AddObjectCommand(editor, hat));&#10;tagClass(hat, &#39;hat&#39;);</code></pre>

<h2><span class="step">4</span> Add it to the scene</h2>

<p class="lede">One <code>AddObjectCommand</code> adds the whole hat, so it is one undo step. Tag the group with a class, add a cool ambient light, a white key light and a violet rim light from behind, set a dark background, and aim the camera:</p>

<pre><code>editor.execute(new AddObjectCommand(editor, new AmbientLight(0xcfc4ff, 0.7)));&#10;const key = new DirectionalLight(0xffffff, 1.6);&#10;key.position.set(5, 8, 6);&#10;editor.execute(new AddObjectCommand(editor, key));&#10;const rim = new DirectionalLight(0x9a7bff, 0.8);&#10;rim.position.set(-6, 4, -5);&#10;editor.execute(new AddObjectCommand(editor, rim));&#10;setBackground(&#39;#1b1530&#39;);&#10;&#10;const cam = editor.camera;&#10;cam.position.set(3.2, 2.6, 5.6);&#10;cam.fov = 45;&#10;cam.lookAt(0.4, 1.6, 0);&#10;cam.updateProjectionMatrix();&#10;editor.controls.center.set(0.4, 1.6, 0);&#10;editor.signals.cameraChanged.dispatch(cam);&#10;editor.signals.objectChanged.dispatch(cam);</code></pre>

<h2><span class="step">5</span> Sculpt the face</h2>

<p class="lede">The smiley is not painted on and not a separate decal object. It is the cone&#39;s own surface, pushed outward. Only the straight lower section (<code>Crown 1</code>) is sculpted, because the face lives on its front. Paste this whole block; the Shell does not allow top-level <code>await</code>, so everything runs inside an <code>async</code> function:</p>

<pre><code>(async () =&gt; {&#10;  const { SetGeometryCommand } = await import(&#39;/editor/js/commands/SetGeometryCommand.js&#39;);&#10;  const crown = editor.scene.getObjectByName(&#39;Crown 1&#39;);&#10;&#10;  // A dense replacement for the crown&#39;s straight section. thetaStart = PI moves the&#10;  // seam to the back of the hat, away from the face (the front is +z).&#10;  const H = 1.3, RT = 0.72, RB = 0.95, RAD = 320, HEI = 140;&#10;  const g = new CylinderGeometry(RT, RB, H, RAD, HEI, true, Math.PI, Math.PI * 2);&#10;  const rAt = t =&gt; RB - (RB - RT) * (t / H); // crown radius at height t&#10;&#10;  // Soft dome falloff: 1 at the centre, 0 at distance 1&#10;  const bump = d =&gt; { const w = Math.min(1, Math.max(0, 1 - d)); return w * w * (3 - 2 * w); };&#10;&#10;  // The face, in surface coordinates: u = arc length around the hat, v = height above the face centre&#10;  const TC = 0.8;&#10;  const MR = 0.21, MY = 0.02, P0 = -2.55, P1 = -0.59; // smile = the lower arc of a circle&#10;  const mouthDist = (u, v) =&gt; {&#10;    const dy = v - MY, rho = Math.hypot(u, dy), ph = Math.atan2(dy, u);&#10;    if (ph &gt;= P0 &amp;&amp; ph &lt;= P1) return Math.abs(rho - MR);&#10;    const e = p =&gt; Math.hypot(u - MR * Math.cos(p), dy - MR * Math.sin(p));&#10;    return Math.min(e(P0), e(P1)); // past the ends of the arc, measure to the nearest end&#10;  };&#10;  const relief = (u, v) =&gt; {&#10;    const base = 0.02 * bump((Math.hypot(u, v) - 0.3) / 0.06); // raised disc, flat top, soft edge&#10;    const eyes = [-0.12, 0.12].reduce((s, ex) =&gt; s + bump(Math.hypot((u - ex) / 0.05, (v - 0.1) / 0.075)), 0) * 0.035;&#10;    const mouth = bump(mouthDist(u, v) / 0.04) * 0.03;&#10;    return base + eyes + mouth;&#10;  };&#10;&#10;  // Push each vertex out along its own normal by the relief height&#10;  const pos = g.attributes.position, nor = g.attributes.normal;&#10;  for (let i = 0; i &lt; pos.count; i++) {&#10;    const x = pos.getX(i), y = pos.getY(i), z = pos.getZ(i);&#10;    const ang = Math.atan2(x, z);&#10;    if (Math.abs(ang) &gt; 0.9) continue; // only the front of the hat can be touched&#10;    const t = y + H / 2;&#10;    const h = relief(ang * rAt(t), t - TC);&#10;    if (h &gt; 0) pos.setXYZ(i, x + nor.getX(i) * h, y + nor.getY(i) * h, z + nor.getZ(i) * h);&#10;  }&#10;  g.computeVertexNormals();&#10;&#10;  // computeVertexNormals leaves a lighting seam where the first and last columns meet; average them&#10;  for (let r = 0; r &lt;= HEI; r++) {&#10;    const a = r * (RAD + 1), b = a + RAD;&#10;    const nx = nor.getX(a) + nor.getX(b), ny = nor.getY(a) + nor.getY(b), nz = nor.getZ(a) + nor.getZ(b);&#10;    const len = Math.hypot(nx, ny, nz) || 1;&#10;    nor.setXYZ(a, nx / len, ny / len, nz / len);&#10;    nor.setXYZ(b, nx / len, ny / len, nz / len);&#10;  }&#10;  nor.needsUpdate = true;&#10;&#10;  // A CylinderGeometry is saved by its parameters (radius, segments...), which would throw the&#10;  // sculpted vertices away on Save. Copy them into a plain BufferGeometry so the file keeps them.&#10;  const baked = new THREE.BufferGeometry();&#10;  baked.setAttribute(&#39;position&#39;, pos);&#10;  baked.setAttribute(&#39;normal&#39;, nor);&#10;  baked.setAttribute(&#39;uv&#39;, g.attributes.uv);&#10;  baked.setIndex(g.index);&#10;&#10;  editor.execute(new SetGeometryCommand(editor, crown, baked)); // one undo step&#10;  editor.deselect();&#10;  return &#39;sculpted &#39; + pos.count + &#39; vertices&#39;;&#10;})()</code></pre>

Why each piece is there:

<ul class="why">&#10;		<li><strong>A dense mesh.</strong> The original cone has 64 sides and one row of height, so it has nowhere to put a ridge a few hundredths of a unit wide. The replacement has 320 sides and 140 rows (about 45,000 vertices); the smile&#39;s ridge spans several vertices instead of one, which is what keeps its edges smooth instead of stair-stepped. <code>openEnded = true</code> drops the caps, which are hidden inside the hat anyway.</li>&#10;		<li><strong>Surface coordinates, not world coordinates.</strong> The face is defined in <code>u</code> (arc length around the hat, <code>angle × radius at that height</code>) and <code>v</code> (height above the face centre). Because the cone is narrower higher up, using the radius at each vertex&#39;s own height keeps the face from stretching into an oval.</li>&#10;		<li><strong>Shapes from falloffs.</strong> <code>bump(d)</code> is a smooth dome: 1 at the centre, 0 at distance 1. An eye is <code>bump</code> of the distance from the eye&#39;s centre, scaled differently in <code>u</code> and <code>v</code> to make an oval. The smile is <code>bump</code> of the distance to an arc: the lower part of a circle, measuring to the nearest end once you are past the arc&#39;s ends. The raised disc is a <code>bump</code> with a flat top. Heights add up: disc 0.02, eyes +0.035, smile 0.03.</li>&#10;		<li><strong>Push along the normal.</strong> Each vertex moves along its own normal by the relief height, not straight out along +z, so the relief follows the cone&#39;s slope and stays the same height everywhere.</li>&#10;		<li><strong>The seam.</strong> A cylinder&#39;s first and last columns of vertices sit on top of each other, and <code>computeVertexNormals</code> leaves them with different normals, which shows as a lighting line. <code>thetaStart = Math.PI</code> moves that seam to the <em>back</em> of the hat (the face is at +z, angle 0), and the loop at the end averages the two columns&#39; normals so it disappears there too.</li>&#10;		<li><strong>Bake it so Save keeps it.</strong> A <code>CylinderGeometry</code> is written to a saved project as its <em>parameters</em> (radii, segment counts), never its vertices, so a sculpted cylinder would reopen as a plain cone. Copying the finished attributes into an ordinary <code>BufferGeometry</code> makes the file store the vertices themselves.</li>&#10;		<li><strong>One undo step.</strong> <code>SetGeometryCommand</code> swaps the geometry through the editor&#39;s history. It is not a Shell global, so it is imported directly. <code>undo()</code> brings back the plain cone and <code>redo()</code> brings back the face.</li>&#10;	</ul>

<h2><span class="step">6</span> Check it</h2>

<p class="lede">Confirm the geometry really changed, and that the sculpt is reversible rather than baked into the scene:</p>

<pre><code>const crown = () =&gt; editor.scene.getObjectByName(&#39;Crown 1&#39;).geometry.attributes.position.count;&#10;editor.scene.getObjectByName(&#39;Crown 1&#39;).geometry.type; // &#39;BufferGeometry&#39;&#10;crown();            // 45261&#10;undo(); crown();    // 388 (the original 64-sided cone is back)&#10;redo(); crown();    // 45261&#10;$S(&#39;.hat&#39;).count(); // 1</code></pre>

<div class="note"><strong>Make the face your own.</strong> Everything lives in <code>relief(u, v)</code>. Change <code>TC</code> to move the face up or down the cone, the eye centres <code>±0.12</code> and the <code>0.035</code> eye height to change the expression, or swap the smile&#39;s arc range <code>P0</code> / <code>P1</code> and radius <code>MR</code> for a frown or a surprised mouth. Re-running the block replaces the old geometry with a freshly sculpted one.</div>

<h2><span class="step">7</span> Open the finished hat</h2>

<p class="lede">The finished scene is public in <code>tejaswigowda/test1</code>: <a href="https://strataeditor.dev/#repo=tejaswigowda/test1&amp;file=hat.json&amp;branch=main">hat.json</a> opens straight in the editor with the brim, the bending cone, the sculpted face, the band, buckle and stars, the three lights and the dark background, all named and tagged as built above.</p>

<div class="note"><strong>What is in the file.</strong> <code>hat.json</code> includes the sculpted face, because step 5 bakes the crown into plain vertex data before it is saved. Saved from the editor&#39;s Git panel, big geometry buffers go out as binary assets next to a small scene file (here about 22 KB of JSON plus a 2.5 MB crown buffer); <strong>File → Save</strong> writes everything inline, about 8.5 MB. Either way the face survives a save and reload, which a <code>CylinderGeometry</code> crown would not.</div>
