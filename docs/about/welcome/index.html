Strata

A deterministic, human-readable selector language for editing and versioning 3D scenes. Sovereign, browser-native, no build. Optional AI that stays within bounds.

Address parts of a scene with CSS-like selectors ($S('.wheel.front')), change them with a closed set of command-backed ops, and version the result with git — every mutation is undoable, git-tracked, and human-readable. AI is a slim, optional front door on top, never a requirement.
