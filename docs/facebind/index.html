Bind a face GLB to a VRM

Drives a base VRM's expression blendshapes from the morphs of a face-blendshape GLB. A weight map only: the VRM's mesh, skeleton, skin weights and face shape are not changed.

Stays on this device. The face GLB is read from a local file and is never fetched from, or sent to, any server. This page makes GET requests only (the base VRM), and the binding works with the network off once the page has loaded.
Expression-bound, not a likeness. This makes the VRM's expressions drivable from the face source. It does not reshape the VRM into the person's face.
