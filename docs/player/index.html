Paste the address of a published render

Plays the HLS set that Strata's Render tab publishes (master.m3u8, fragmented MP4 segments, render.json). Safari plays it natively; elsewhere hls.js (Apache-2.0) does. The address is the page's hash: /player/#https://strataeditor.dev/video/<name>/v1/. If that host does not answer, the render's listed mirrors are tried in order.
